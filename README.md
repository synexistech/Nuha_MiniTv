# Nuha's Mini TV 📱👶

Aplikasi mobile yang cantik dan selamat untuk Nuha Ammara menonton video pendidikan Ms Rachel dengan kawalan screen time untuk ibu bapa.

## Ciri-ciri Utama ✨

### 🎥 Video Pembelajaran Ms Rachel
- **Huruf**: Video pembelajaran ABC dan phonetics
- **Nombor**: Belajar kira dan nombor 1-10
- **Warna**: Mengenal pasti warna-warna dengan Ms Rachel
- **Lagu**: Lagu pendidikan dan nursery rhymes
- **Haiwan**: Belajar tentang haiwan dan bunyi mereka

### ⏰ Kawalan Screen Time
- Had masa 45 minit (boleh ubah: 15-60 minit)
- Visual countdown dengan warna (hijau → oren)
- Auto-lock apabila masa tamat
- Emergency stop button untuk ibu bapa

### 🔒 Kawalan Ibu Bapa
- PIN 4-digit untuk akses parent controls
- Adjustable screen time limit
- Auto-play toggle
- Volume lock option

### 🎨 Reka Bentuk Baby-Friendly
- Tema soft pink yang cantik
- Button besar-besar untuk baby
- Icon comel dan Warna-warni
- Typography yang mudah dibaca

## Cara Gunakan 🛠️

### Untuk Baby (Nuha):
1. Buka aplikasi
2. Pilih kategori yang disuka:
   - 🅰️ Letters - Belajar huruf
   - 🔢 Numbers - Belajar nombor  
   - 🌈 Colors - Belajar warna
   - 🎵 Songs - Dengar lagu
   - 🐱 Animals - Belajar haiwan
3. Tunggu video playing
4. Enjoy! ✨

### Untuk Ibu Bapa:
1. **Access Parent Controls**: Tekan gear icon (⚙️) di bottom-left
2. **Enter PIN**: Default PIN = `1234`
3. **Adjust Settings**:
   - Screen time: 15-60 minit
   - Auto-play: On/Off
   - Sound lock: On/Off

## Install sebagai App 📱

### Android:
1. Buka browser (Chrome/Samsung Internet)
2. Pergi ke website
3. Tap menu (⋮) → "Add to Home screen"
4. Confirm "Add"

### iOS (Safari):
1. Buka Safari
2. Pergi ke website
3. Tap Share button → "Add to Home Screen"
4. Name: "Nuha's Mini TV" → "Add"

## Safety Tips 🛡️

### Panduan Screen Time untuk Bayi 12 bulan:
- ✅ **Supervision**: Sentiasa supervise Nuha quando using app
- ✅ **Breaks**: Beri break setiap 15-20 minit
- ✅ **Content**: Video Ms Rachel sesuai untuk idade
- ✅ **Volume**: Jangan terlalu kuat untuk hearing Nuha

### Emergency Procedures:
- 🚨 **Stop immediately**: Tekan STOP button (merah)
- 🚨 **Close app**: Use home button
- 🚨 **PIN if forgotten**: Contact parent untuk reset

## Troubleshooting 🔧

### Video tidak load:
1. Check internet connection
2. Refresh page
3. Try different category

### Timer tidak berfungsi:
1. Reload app
2. Check browser permissions

### App tidak install:
1. Try different browser
2. Clear browser cache
3. Try incognito mode
